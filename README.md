# وب‌سایت برند رسمی SEA BREW (قهوه آماده مصرف ساحل جنوب)

یک وب‌سایت معرفی تک‌صفحه‌ای، کاملاً استاتیک، مدرن و سینمایی با طراحی هویت اختصاصی بر پایه‌ی کانسپت «دریای گرم» جنوب ایران (بوشهر).

---

## ۱. ساختار پروژه

```text
├── public/
│   ├── fonts/
│   │   └── Estedad-Variable.woff2   # فونت متغیر استعداد با وزن‌های ۱۰۰ تا ۹۰۰
│   ├── favicon.svg                  # فاوآیکون اختصاصی بر پایه دو موج و خورشید
│   ├── og-image.svg                 # پیش‌نمایش متادیتا شبکه‌های اجتماعی
│   ├── robots.txt
│   └── sitemap.xml
├── src/
│   ├── components/
│   │   ├── sections/                # ۸ سکشن اصلی به ترتیب روایت روز
│   │   │   ├── Hero.tsx             # سکشن ۱: هیرو با انیمیشن ورود، غروب خورشید و پارالاکس ۳ لایه
│   │   │   ├── Statement.tsx        # سکشن ۲: بیانیه برند با آشکارسازی اسکرول کلمه‌به‌کلمه
│   │   │   ├── Interlude.tsx        # سکشن ۳: میان‌پرده صحنه خطی با پارالاکس عمیق و مختصات فارسی
│   │   │   ├── Drinks.tsx           # سکشن ۴: کارت‌های طاقی نوشیدنی‌ها (دم‌آوری و تازه) با ریل افقی
│   │   │   ├── ProductMoment.tsx    # سکشن ۵: لحظه محصول و بالا آمدن مایع در لیوان با آستانه‌های ۲۵/۵۰/۷۵
│   │   │   ├── Story.tsx            # سکشن ۶: روایت سه‌فصل جنوب/قهوه/دریا و ترنزیشن طاقی شب
│   │   │   ├── FindUs.tsx           # سکشن ۷: نقاط عرضه و کافه‌ها با وضوح تجاری
│   │   │   └── Contact.tsx          # سکشن ۸: فرم ارتباط و کانال‌های رسمی

│   │       ├── ArchFrame.tsx        # کادر طاق معماری جنوب با ماسک دقیق
│   │       ├── Button.tsx           # دکمه امضای برند با موج و تاب خوردن ارگانیک
│   │       ├── Cursor.tsx           # کرسر اختصاصی خورشید و حلقه Difference (فقط دسکتاپ)
│   │       ├── Footer.tsx           # فوتر با وردمارک بزرگ بالا رونده و نشانگر خط افق

│   │       ├── Marquee.tsx          # نوار متحرک بی‌نهایت حساس به سرعت اسکرول
│   │       ├── NavBar.tsx           # ناوبری چسبنده با منوی تمام‌صفحه طاقی موبایل
│   │       ├── Preloader.tsx        # پریلودر طلوع خورشید، رسم امواج و ارقام فارسی
│   │       ├── SunDot.tsx           # نقطه امضای برند (خورشید طلایی)
│   │       └── TideLine.tsx         # خط افق دریا و نشانگر اسکرول کل صفحه
│   ├── lib/
│   │   └── motion.ts                # تنظیمات GSAP، پلاگین‌ها و منحنی‌های اختصاصی (tide, pour, swell)
│   ├── content.ts                   # تنها منبع حقیقت تمامی متون سایت (Single Source of Truth)
│   ├── index.css                    # تم تیل‌ویند، قوانین فونت، متغیرها و رفتارهای حرکتی
│   ├── App.tsx                      # چیدمان و ترکیب‌بندی سکشن‌ها
│   └── main.tsx                     # مدخل اجرای React
├── CONTENT.md                       # شناسنامه و جدول کلیه اقلام [محتوا لازم است]
├── index.html                       # ساختار HTML منطبق بر سئو و جهت راست‌به‌چپ (dir="rtl")
└── metadata.json
```

## ۲. مشخصات دیزاین سیستم و پالت رنگی

- **کرم (Cream)**: `#FFFADE` — بوم روز و فضای تنفس اصلی
- **جوهر (Ink)**: `#161617` — متن اصلی، کنتراست تیره و بوم شب
- **طلا (Gold)**: `#A78040` — خطوط معماری، مرز طاق‌ها و جزئیات ظریف
- **مارون (Maroon)**: `#825F27` — سایه‌ها و وزن میانی
- **خورشید (Sun)**: `#FDB716` — نقطه امضای برند (`SunDot`) در ابعاد مشخص
- **گردوغبار (Dust)**: `#C9B8B6` — فاز گرم میانه روز
- **شیشه دریا (Sea Glass)**: `#7FA096` — لهجه ظریف آب و دریا (کمتر از ۲٪ سطح)

---

## ۳. نحوه بروزرسانی محتوا
تمامی متن‌ها در فایل `src/content.ts` متمرکز شده‌اند. برای مشاهده لیست کامل فیلدهای نیازمند متن یا تغییر، فایل `CONTENT.md` را مطالعه کنید.

---

## ۴. انطباق با قوانین دسترسی‌پذیری و Reduced-Motion
در صورت فعال بودن گزینه `prefers-reduced-motion: reduce` در سیستم‌عامل کاربر:
- پریلودر بلافاصله رد می‌شود.
- انیمیشن‌های پارالاکس و چرخش متوقف شده و عناصر بدون پرش نمایش داده می‌شوند.
- کرسر سفارشی غیرفعال شده و به کرسر استاندارد سیستم‌عامل بازمی‌گردد.
